🔹 1. Groupes ▶

Définition : Un groupe $(G, \star)$ est un ensemble muni d'une loi de composition interne associative, possédant un élément neutre $e$ et où tout élément admet un symétrique.

📌 Exemples

$(\mathbb{Z},+)$ est un groupe abélien (commutatif).
$(\mathbb{R}^*,\times)$ est un groupe abélien.
$GL_n(\mathbb{R})$ (matrices inversibles) est un groupe non commutatif pour la multiplication.
Le groupe symétrique $S_n$ (permutations) est non commutatif pour $n\ge 3$.

📌 Propriétés

Le neutre est unique. Le symétrique de $x$ est unique.
Dans un groupe, tout élément est régulier : $ax = bx \Rightarrow a = b$.

🔹 2. Anneaux ▶

Définition : Un anneau $(A,+,\times)$ est un ensemble muni de deux lois : $(A,+)$ est un groupe abélien, $\times$ est associative, distributive par rapport à $+$, et possède un élément neutre $1$ (anneau unitaire). Si $\times$ est commutative, l'anneau est commutatif.

📌 Exemples

$(\mathbb{Z},+,\times)$ est un anneau commutatif unitaire intègre.
$(\mathbb{R}[X],+,\times)$ est un anneau commutatif.
$(\mathcal{M}_n(\mathbb{R}),+,\times)$ est un anneau non commutatif (pour $n\ge2$).

📌 Divisibilité et idéaux

Dans un anneau intègre : $a$ divise $b$ s'il existe $c$ tel que $b = ac$.
Un idéal $I$ est un sous-groupe additif tel que pour tout $a\in A, x\in I$, $ax \in I$.

🔹 3. Corps ▶

Définition : Un corps $(\mathbb{K},+,\times)$ est un anneau commutatif unitaire où tout élément non nul admet un inverse pour la multiplication.

📌 Exemples

$\mathbb{Q}, \mathbb{R}, \mathbb{C}$ sont des corps.
$\mathbb{Z}/p\mathbb{Z}$ (avec $p$ premier) est un corps fini.
$\mathbb{Z}$ n'est pas un corps (2 n'a pas d'inverse dans $\mathbb{Z}$).

📌 Caractéristique

La caractéristique d'un corps est le plus petit entier $n>0$ tel que $n\cdot 1 = 0$, ou $0$ si aucun. Ex : $\mathbb{R}$ est de caractéristique $0$, $\mathbb{Z}/p\mathbb{Z}$ de caractéristique $p$.

🔹 4. Espaces vectoriels & Applications linéaires ▶

Définition : Un $\mathbb{K}$-espace vectoriel $E$ est un ensemble muni d'une addition interne et d'une multiplication externe par les scalaires de $\mathbb{K}$, vérifiant les axiomes usuels.

📌 Bases et dimension

Une base de $E$ est une famille libre et génératrice. Tout espace vectoriel admet une base. La dimension est le cardinal d'une base (si fini).

Ex : $\mathbb{R}^n$ est de dimension $n$. L'ensemble des polynômes de degré $\le n$ est un espace vectoriel de dimension $n+1$.

📌 Applications linéaires

$f: E \to F$ est linéaire si $f(u+v)=f(u)+f(v)$ et $f(\lambda u)=\lambda f(u)$.
Noyau : $\ker f = \{u \in E \mid f(u)=0\}$ (sous-espace de $E$).
Image : $\operatorname{Im} f = f(E)$ (sous-espace de $F$).
Théorème du rang : $\dim E = \dim \ker f + \dim \operatorname{Im} f$.
